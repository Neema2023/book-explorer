# Book Explorer

## About the Project
Book Explorer is a responsive web application that allows users to explore books, search for books, view book information, and manage their favorite books.

## Features
- Responsive multi-page layout
- Search for books
- Fetch book data from an API
- Display book information
- Add and remove favorite books
- Store favorite books using Local Storage
- Interactive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- JavaScript Modules
- Fetch API
- Local Storage
- Git and GitHub

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Neema2023/book-explorer.git
   ```

2. Open the project folder:

   ```bash
   cd book-explorer
   ```

3. Open `index.html` in your browser or use Live Server in Visual Studio Code.
